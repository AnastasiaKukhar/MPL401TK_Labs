# MPL401TK_Labs
Кухар Анастасія Романівна
Група: 401ТК
Номер варіанта: 13 (1)
Предметна область: Інтернет магазин
Версія .NET: net10.0

Предметна область Інтернет магазин складається з сутностей: Користувач, товар, замовлення, кошик. Користувач вибирає товари та додає їх у кошик. Далі на основі вмісту кошика формується замовлення, яке прив'язується до цього конкретного користувача.
