# MPL401TK_Labs
Кухар Анастасія Романівна
Група: 401ТК
Номер варіанта: 13 (1)
Предметна область: Інтернет магазин
Версія .NET: net10.0

Базова логіка інтернет-магазину побудована навколо товарів, користувачів, кошиків та замовлень. Покупець обирає продукцію і додає її в кошик, на основі якого автоматично оформлюється його персоналізоване замовлення.
